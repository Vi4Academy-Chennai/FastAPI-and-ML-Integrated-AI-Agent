Executive Summary

Architecture Overview: Bridging LLMs & ML

Why do we connect AI Agents to ML Models?

  • Large Language Models (LLMs): Exceptional at natural language understanding, extraction, and reasoning, but incapable of precise real-time predictive math on custom datasets[cite: 1].
  • Machine Learning Models: Exceptional at numerical calculations, pattern recognition, and predictions (e.g., price estimation), but lack conversational capabilities[cite: 1].
  • FastAPI: Acts as the high-performance REST API bridge connecting the LLM Agent to the Predictive ML Model[cite: 1].

Backend Integration

What is an API & Why FastAPI?

Understanding APIs

An Application Programming Interface (API) is a software intermediary that allows two separate applications to communicate with each other[cite: 2]. APIs are the backbone of modern web services, mobile app backends, and microservice architectures[cite: 2].

Why FastAPI?

  • Extremely Fast: Performs on par with Node.js and Go, making it one of the fastest Python frameworks available, utilizing Starlette and Pydantic[cite: 2].
  • Fast to Code: Utilizes Python type hints for excellent editor support and reduced debugging[cite: 2].
  • Automatic Documentation: Generates interactive Swagger UI and ReDoc based on your code[cite: 2].
  • Built-in Async Support: Natively supports asynchronous programming for handling concurrent requests efficiently[cite: 2].
FastAPI Mechanics

FastAPI Request Lifecycle & Basics

Request Lifecycle

  1. Client Request: Client sends an HTTP request[cite: 2].
  2. ASGI Server: Uvicorn receives the request and passes it to FastAPI[cite: 2].
  3. Routing: Routes the request to the matching function[cite: 2].
  4. Validation: Pydantic validates data; instantly returns 422 if invalid[cite: 2].
  5. Execution: Python function runs its logic[cite: 2].
  6. Serialization: Returned data converts to JSON automatically[cite: 2].

Request Parameters

  • Path Parameters: Variables embedded in the URL (e.g., /users/{user_id})[cite: 2].
  • Query Parameters: Key-value pairs attached to the end of the URL (e.g., ?limit=10)[cite: 2].
  • Request Body: JSON data parsed via Pydantic BaseModel[cite: 2].
  • Response Types: Status Codes, Response Models, or Custom Responses[cite: 2].
FastAPI Implementation

Simple FastAPI Setup & Testing

Initialize a simple application demonstrating path parameters, query parameters, and a request body[cite: 2].

from fastapi import FastAPI, status
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float

@app.post("/items/", status_code=status.HTTP_201_CREATED)
def create_item(item: Item):
    return {"item_name": item.name, "status": "Item created successfully"}

To run the API locally, execute: fastapi dev main.py[cite: 2]. Test the interactive docs by visiting http://127.0.0.1:8000/docs[cite: 2].

Machine Learning

What is Machine Learning (ML)?

Machine Learning is a subset of AI that focuses on building systems that learn from data. Instead of explicitly programming a computer, you feed it data and allow algorithms to discover patterns[cite: 4].

Types of Machine Learning[cite: 4]

  • Supervised Learning: The model is trained on labeled data (input-output pairs) to learn the mapping and predict outputs for unseen inputs (e.g., predicting house prices)[cite: 4].
  • Unsupervised Learning: The model is given unlabeled data and must find hidden structures or groupings on its own (e.g., customer segmentation)[cite: 4].
  • Reinforcement Learning: An agent learns to make decisions by performing actions in an environment to maximize a reward[cite: 4].
Machine Learning

Linear Regression in Detail

Linear Regression is a fundamental Supervised Learning algorithm used for predicting a continuous numerical value[cite: 4]. It assumes a linear relationship between input variables ($X$) and the target output ($y$)[cite: 4].


The Equation: $$y = mx + b$$[cite: 4]

  • $y$ is the predicted output[cite: 4].
  • $x$ is the input feature[cite: 4].
  • $m$ is the slope (weight)[cite: 4].
  • $b$ is the y-intercept (bias)[cite: 4].

Scikit-Learn Implementation[cite: 4]

Agentic AI Part 1

Core AI Agent Architecture

An AI Agent is an autonomous system that uses an LLM as its reasoning engine to perceive intent, plan actions, interact with external tools, and achieve a goal[cite: 6].

The Agent Lifecycle[cite: 6]

  1. Perception: Reads user input and history[cite: 6].
  2. Reasoning: Evaluates if it needs tools[cite: 6].
  3. Action: Emits structured tool calls[cite: 6].
  4. Observation: Ingests external tool data[cite: 6].
  5. Synthesis: Produces a natural-language response[cite: 6].

OpenAI Client SDK[cite: 6]

The openai Python SDK serves as an industry-standard interface. It can be pointed to alternate infrastructures like Groq for high-speed LPU inference[cite: 6].

Agentic AI Part 2

Tool Function vs. Schema & The Two-Step Cycle

Schema vs. Execution

  • Tool Schema: Defines what functions exist and their parameters. The LLM never executes Python code directly; it outputs JSON conforming to this schema[cite: 6].
  • Tool Function: The actual Python code in your environment that performs the network request or database query[cite: 6].

Two-Step Cycle[cite: 6]

Turn 1: Pass user messages + tools. LLM returns a tool_calls object instead of text[cite: 6].

Execution: Script executes the Python function[cite: 6].

Turn 2: Pass prompt + tool_calls + tool output back to the LLM. LLM synthesizes the final text response[cite: 6].

Agentic AI Part 3

UI & Serving Architecture

Streamlit Concepts

  • Execution Model: Runs the script top-to-bottom every time a widget is interacted with[cite: 6].
  • st.session_state: Persistent key-value store across reruns to preserve conversation memory[cite: 6].
  • st.chat_message: Built-in chat interface elements[cite: 6].

Why FastAPI Here?

Instead of placing the Scikit-Learn model directly in Streamlit, it is isolated in FastAPI for[cite: 6]:

  • Separation of Concerns: ML inference isolated from UI[cite: 6].
  • Independent Scalability: ML server can scale on GPUs[cite: 6].
  • Strict Validation: Leveraging Pydantic[cite: 6].

Code Walkthrough Part 2

Step-by-Step: Streamlit AI Agent

AI_Agent.py orchestrates the interaction[cite: 6]:

  • Tool Handler: Python packages arguments into a JSON payload and makes a requests.post call to the local FastAPI server[cite: 6].
  • Interaction Loop: Prompt added to session_state.messages. Agent checks if all required schema parameters are met. If met, the LLM emits a tool call[cite: 6].
  • Synthesis: The tool output is appended under the tool role, and a second API call occurs to translate raw numerical output into a complete advisory response[cite: 6].
